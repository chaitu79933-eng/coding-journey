Welcome to my coding journey!

## Project 1: Student Grade Calculator

A beginner Python program that calculates a student's total marks, average marks, and grade.

### What I learned

- Python variables
- User input
- `int()` and `float()`
- Arithmetic operations
- `if`, `elif`, and `else`
- Basic Git and GitHub workflow

### How to run

1. Make sure Python is installed.
2. Open the project in VS Code.
3. Run `grade_calculator.py`.
4. Enter the student's name and marks.
